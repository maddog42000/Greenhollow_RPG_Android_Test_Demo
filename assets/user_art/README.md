# User-supplied Greenhollow pixel-art sheet

`greenhollow_sprite_sheet_source.png` is the original image supplied for this art pass. `greenhollow_sprite_atlas.png` is a non-destructive RGBA copy with its bright-magenta chroma-key background made transparent. The game references atlas regions directly for foliage, village buildings, fence/flower props, stream dressing, and ambient forest wisps. The original image is retained unchanged for future atlas-region adjustments.

The sheet's sprites are drawn with nearest-neighbour project filtering to preserve their pixel-art edges.
